Escribe un programa, pulsa Compilar y revisa cada fase: léxico → sintaxis (AST) → semántica → código intermedio → ejecución.

Código fuente

Gramática (BNF)

programa  → sentencia*
sentencia → ID "=" expr ";"
          | "mostrar" expr ";"
expr      → term (("+" | "-") term)*
term      → factor (("*" | "/") factor)*
factor    → NUM | ID | "(" expr ")" | "-" factor

El analizador léxico convierte el texto en tokens (lexema, tipo, línea y columna).
